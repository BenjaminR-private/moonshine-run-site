# Moonshine Run

A portrait car-chase game: haul moonshine down country roads and outrun the law. Coming to Google Play; iPhone later.

## Support

Anyone can email **moonshine-run@proton.me** with questions or problems. For a bug, please say which phone you use and what happened just before it. Please don't include anything personal that isn't needed to answer you.

## Feedback reports

The game can save a detailed feedback or bug report file. These report files are part of a feedback pilot open only to invited adult testers, who receive the details with their invitation. If you are not an invited tester, please don't send report files; describe the problem in a normal email instead.

## Privacy

The game has no internet access and sends nothing automatically. Read the [privacy policy]({{ '/privacy/' | relative_url }}).
